⚙ NotaTrack — Project Overview

- What is NotaTrack?

NotaTrack is the official project I developed for my internship. It was built directly following company requirements, focusing on improving inventory logging and document management

This system was created to help manage daily operational data more efficiently, reduce manual errors, and simplify the workflow for staff members.

- Key Features

NotaTrack includes several important and company-needed functions:

  • ✔ Sales & service note recording
  • ✔ Inventory item logging
  • ✔ Invoice / purchase note handling
  • ✔ Pixel-inspired UI for clarity
  • ✔ Cleaner and more structured data workflow
