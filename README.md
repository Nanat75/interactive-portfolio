## 🏡 About This Project

This is **not a normal portfolio website**.

It’s an **interactive pixel-art experience**, inspired by cozy games like  
**OMORI**, classic RPGs, and room-exploration mechanics.

Instead of scrolling, visitors:
- Walk around a room
- Interact with objects
- Unlock areas
- Discover information naturally ✨

The goal?  
👉 Make learning about me feel **personal, playful, and memorable!**.

---

## 🎮 Features

✨ Game-style navigation (keyboard-based)  
✨ Pixel-art environment & UI  
✨ Interactive objects (notes, shelves, doors, TV, diary. and more)  
✨ Locked-room mechanics (keys, Task, fragments)  
✨ Soft background music & sound effects  
✨ Exit choice system (leave or stay longer)  
✨ Pastel + cozy pixel aesthetic  

---

## 🗺️ Rooms & Interactions

- 🛋️ **Living Room** — Welcome note & intro  
- 📺 **TV** — Home Section & fun facts  
- 📓 **Diary** — About me 
- 🍰 **Kitchen** — Skills as a mini-game  
- 🧰 **Workshop** — Projects  
- 🌿 **Shelf + Plant** — Social media links  
- 🚪 **Exit Door** — Choice-based ending
