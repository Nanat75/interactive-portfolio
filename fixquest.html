⚙ FixQuest — Project Overview

- What is FixQuest?

FixQuest is a personal side project developed during my internship period. It was not requested by the company. instead, I created it because I identified a "workflow gap" in how repair tasks were tracked and reported inside the system.

This project allowed me to experiment with UI design, CRUD operations, and problem-solving while still staying aligned with real company needs.

- Key Features

FixQuest includes several essential features:

  • ✔ Repair job creation (CRUD)
  • ✔ Progress tracking system
  • ✔ Task assignment view
  • ✔ Pixel-inspired UI for clarity
  • ✔ Lightweight, simple workflow improvement
